📖 How to Use with Claude Web

For Claude: This interface allows you to interact with the localhost bridge server. The user will execute commands here, and you can read the results.

Instructions for Claude:

  1. Ask the user to open this page: https://YOUR-USERNAME.github.io/YOUR-REPO/claude-bridge-proxy.html
  2. Tell the user which API endpoint to call (e.g., "Call /api/status")
  3. User selects the endpoint and clicks "Send Request"
  4. Read the response from the response box below
  5. Provide analysis or next steps based on the response

⚠️ Security: The bridge server exposes the filesystem and connected accounts. It must require the API Token above on every request, restrict CORS to this page's origin only (never *), validate the Host header to block DNS rebinding, allow-list permitted filesystem paths, and bind to 127.0.0.1. See SECURITY.md.
